## 1. Missing Number

**[문제 링크](https://leetcode.com/problems/missing-number/)** · `Easy` · Python · `자력해결`

**입출력**
- `0 ~ n` 범위의 서로 다른 숫자 `n`개가 담긴 배열 `nums`가 주어진다. (`1 <= n <= 10^4`)
- 범위 안에서 배열에 없는 숫자 하나를 반환한다.

**접근**
1. 브루트포스: `0 ~ n`의 각 숫자마다 `nums`에 있는지 `in`으로 확인한다.
2. 한계: 리스트에서 `in`은 `O(n)`이므로 전체가 `O(n^2)`이 된다.
3. 최종: 등장한 숫자를 딕셔너리에 기록해 두고, `0 ~ n-1` 중 기록에 없는 숫자를 반환한다. 모두 있으면 빠진 숫자는 `n`(= 최댓값 + 1)이다.

**선택 근거**
딕셔너리(해시맵)는 key 조회가 평균 `O(1)`이라, "이 숫자가 있었나?"를 반복해서 물어볼 때 리스트보다 훨씬 빠르다.

**복잡도**
- 시간: `O(n)` — `nums`를 한 번 순회해 기록하고, `0 ~ n-1`을 한 번 순회하며 `O(1)`로 조회한다. 마지막 `max()`도 `O(n)`이다.
- 공간: `O(n)` — 숫자 `n`개를 저장하는 딕셔너리를 사용한다.

**엣지 케이스**
- [ ] 빠진 숫자가 `n`인 경우 (`[0, 1]` → `2`): `0 ~ n-1` 순회에서 못 찾으므로 `max + 1`을 반환한다.
- [ ] 빠진 숫자가 `0`인 경우 (`[1]` → `0`): 첫 반복에서 바로 `0`을 반환한다.
- [ ] 원소가 하나뿐인 경우 (`[0]` → `1`): `max(duplicate) + 1 = 1`을 반환한다.

**코드**

```python
class Solution:
    def missingNumber(self, nums: list[int]) -> int:
        duplicate = {}

        for i, num in enumerate(nums):
            duplicate[num] = True

        for a in range(len(nums)):
            if a not in duplicate:
                return a
        return max(duplicate)+1
```

**다시 볼 때의 트리거**
> "범위 안에서 빠진 하나"는 해시로 존재 여부를 체크하거나, `0 ~ n`의 합에서 배열의 합을 빼면 된다.

<details><summary>선택 항목</summary>

- **소요 시간 / 막힌 지점:** 빠진 숫자가 `n`일 때는 `0 ~ n-1` 순회로 찾을 수 없어서 마지막에 따로 처리해야 했다.
- **복습 필요:** [ ] 합 공식(`n*(n+1)//2 - sum(nums)`)이나 XOR로 공간 `O(1)` 풀이 연습하기

</details>

## 2. Invert Binary Tree

**[문제 링크](https://leetcode.com/problems/invert-binary-tree/)** · `Easy` · Python · `자력해결`

**입출력**
- 이진 트리의 루트 `root`가 주어진다. (노드 수 `0 ~ 100`, 값 범위 `-100 ~ 100`)
- 모든 노드의 왼쪽/오른쪽 자식을 좌우 반전한 트리의 루트를 반환한다.

**접근**
1. 브루트포스: 트리를 레벨별로 읽어 각 레벨의 순서를 뒤집은 뒤 새 트리를 만든다.
2. 한계: 새 트리를 다시 구성해야 해서 코드가 길고 추가 공간도 많이 든다.
3. 최종: 재귀로 현재 노드의 `left`, `right`를 교환하고, 양쪽 서브트리에도 같은 작업을 맡긴다.

**선택 근거**
"트리 전체를 뒤집는다" = "모든 노드에서 두 자식을 바꾼다"이므로, 각 노드에서 할 일이 똑같아 재귀로 자연스럽게 표현된다.

**복잡도**
- 시간: `O(n)` — 모든 노드를 정확히 한 번씩 방문한다.
- 공간: `O(h)` — 재귀 호출 스택의 깊이가 트리 높이 `h`만큼 쌓인다. 균형 트리면 `O(log n)`, 한쪽으로 치우친 트리면 최악 `O(n)`이다.

**엣지 케이스**
- [ ] 빈 트리 (`root = None`): 종료 조건에서 바로 `None`을 반환한다.
- [ ] 자식이 한쪽만 있는 노드: `None`과 노드를 교환하면 되고, `None` 쪽 재귀는 종료 조건에서 끝난다.

**코드**

```python
class Solution:
    def invertTree(self, root: TreeNode | None) -> TreeNode | None:
        if root is None:
            return None

        root.left, root.right = root.right, root.left

        self.invertTree(root.left)
        self.invertTree(root.right)

        return root
```

**다시 볼 때의 트리거**
> 트리 변형 문제는 "종료 조건 → 내 노드에서 할 일 → 자식에게 재귀로 맡기기" 순서로 쓴다.

<details><summary>선택 항목</summary>

- **소요 시간 / 막힌 지점:** 파이썬의 튜플 교환(`a, b = b, a`) 덕분에 임시 변수 없이 자식을 바꿀 수 있었다.
- **복습 필요:** [ ] BFS(큐)로 같은 문제를 반복문으로 풀어보기

</details>

## 이번 주 패턴 정리

존재 여부를 반복해서 확인해야 할 때는 리스트 대신 해시맵을 쓰면 조회가 `O(1)`이 된다. 트리 문제는 각 노드에서 할 일이 같다는 점을 이용해, 종료 조건과 "내 노드에서 할 일"만 정하고 나머지는 재귀로 자식에게 맡기면 된다. 이때 공간 복잡도는 재귀 스택 깊이, 즉 트리 높이 `O(h)`로 계산한다.
