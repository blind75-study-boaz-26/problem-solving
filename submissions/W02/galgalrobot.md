## 1. Two Sum

**[문제 링크](https://leetcode.com/problems/two-sum/)** · `Easy` · Python · `자력해결`

**입출력**
- 정수 배열 `nums`와 목표값 `target`이 주어진다. 서로 다른 두 인덱스의 값 합이 `target`이 되는 해가 항상 하나 존재한다.
- 조건을 만족하는 두 인덱스를 배열로 반환한다.

**접근**
1. 브루트포스: 모든 두 원소 조합을 확인해 합이 `target`인지 검사한다.
2. 한계: 두 수를 고르는 중첩 반복문 때문에 시간 복잡도가 `O(N^2)`이다.
3. 최종: 현재 값의 보수 `target - num`을 해시맵에서 찾고, 없으면 현재 값과 인덱스를 저장한다.

**선택 근거**
해시맵은 보수의 존재 여부와 인덱스 조회를 평균 `O(1)`에 처리하므로, 배열을 한 번만 순회할 수 있다.

**복잡도**
- 시간: `O(N)` — 배열을 최대 한 번 순회한다.
- 공간: `O(N)` — 방문한 값과 인덱스를 해시맵에 저장한다.

**엣지 케이스**
- [ ] 같은 값 두 개가 답인 경우: 첫 번째 값을 저장한 뒤 두 번째 값에서 보수를 찾아 반환한다.
- [ ] 음수 또는 0이 포함된 경우: 뺄셈으로 보수를 계산하므로 같은 방식으로 처리한다.
- [ ] 현재 코드의 반환값 확인: `return seen[complement], num`은 두 번째 인덱스가 아니라 현재 값 `num`을 반환한다. 제출 전 `return [seen[complement], i]`로 수정해야 한다.

**코드**

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}  # 숫자의 값과 인덱스를 저장할 해시 맵(딕셔너리)이다.
        
        for i, num in enumerate(nums):  # 리스트를 순회하며 인덱스(i)와 값(num)을 하나씩 가져온다.
            complement = target - num   # target을 만들기 위해 현재 숫자(num)에 더해야 하는 '수'를 구한다.
            
            if complement in seen:      # 구한 보수가 이미 해시 맵(seen)에 존재한다면
                return seen[complement], num  # 보수의 인덱스와 현재 숫자 값을 반환한다.
                
            seen[num] = i               # 존재하지 않는다면, 현재 숫자와 그 인덱스를 해시 맵에 기록한다.
```

**다시 볼 때의 트리거**
> 두 수의 합을 찾을 때는 현재 수의 보수를 해시맵에서 먼저 조회한다.

## 2. Best Time to Buy and Sell Stock

**[문제 링크](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)** · `Easy` · Python · `자력해결`

**입출력**
- 날짜 순서대로 주어진 주식 가격 배열에서 한 번 매수한 뒤 미래 날짜에 한 번 매도할 수 있다.
- 가능한 최대 이익을 반환하며, 이익을 낼 수 없으면 `0`을 반환한다.

**접근**
1. 브루트포스: 모든 매수일과 그 이후의 매도일을 비교한다.
2. 한계: 가능한 날짜 쌍을 모두 확인하면 시간 복잡도가 `O(N^2)`가 된다.
3. 최종: 현재까지의 최저 매수가를 유지하면서 현재 가격에 팔았을 때의 이익과 최대 이익을 갱신한다.

**선택 근거**
미래의 매도 가격마다 필요한 정보는 이전까지의 최저 가격뿐이므로, 그리디하게 최저 가격과 최대 이익만 저장한다.

**복잡도**
- 시간: `O(N)` — 가격 배열을 한 번 순회한다.
- 공간: `O(1)` — 최저 가격과 최대 이익 변수만 사용한다.

**엣지 케이스**
- [ ] 가격이 계속 하락하는 경우: `max_profit`을 `0`으로 유지해 `0`을 반환한다.
- [ ] 가격 배열이 비어 있거나 가격이 하나뿐인 경우: 거래할 수 없으므로 `0`을 반환한다.
- [ ] 최저 가격이 중간에 갱신되는 경우: 이후 날짜의 매도 이익 계산에 새 최저 가격을 사용한다.

**코드**

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        min_price = float('inf')  # 최솟값을 무한대로 초기화
        max_profit = 0            # 최대 이익을 0으로 초기화
        
        for price in prices:
            if price < min_price:
                min_price = price  # 더 싼 가격을 만나면 최솟값 갱신
            else:
                profit = price - min_price  # 오늘 팔았을 때의 이익 계산
                if profit > max_profit:
                    max_profit = profit     # 최대 이익 갱신
                    
        return max_profit
```

**다시 볼 때의 트리거**
> 한 번 순회하며 과거의 최솟값과 현재까지의 최댓값을 함께 유지한다.

- **소요 시간 / 막힌 지점:** 처음에는 배열을 절반으로 나누는 방법을 시도했지만 반례가 있어, 매수 가능 범위를 한 번 순회하는 방식으로 바꿨다.

## 3. Contains Duplicate

**[문제 링크](https://leetcode.com/problems/contains-duplicate/)** · `Easy` · Python · `자력해결`

**입출력**
- 정수 배열 `nums`가 주어진다. 배열의 길이는 1 이상이며 값은 중복될 수 있다.
- 같은 값이 두 번 이상 나타나면 `True`, 모든 값이 다르면 `False`를 반환한다.

**접근**
1. 브루트포스: 각 원소를 다른 모든 원소와 비교해 같은 값이 있는지 확인한다.
2. 한계: 중첩 반복문이 필요해 시간 복잡도가 `O(N^2)`가 된다.
3. 최종: 지금까지 본 값을 해시맵에 저장하고, 이미 존재하는 값을 만나면 즉시 `True`를 반환한다.

**선택 근거**
해시맵의 키 조회와 삽입은 평균 `O(1)`이므로 정렬하지 않고 중복 여부를 한 번에 확인할 수 있다.

**복잡도**
- 시간: `O(N)` — 배열을 최대 한 번 순회한다.
- 공간: `O(N)` — 중복이 없을 때 모든 값을 저장한다.

**엣지 케이스**
- [ ] 배열에 같은 값이 바로 연속해서 나오는 경우: 두 번째 값을 조회할 때 즉시 `True`를 반환한다.
- [ ] 음수나 0이 포함된 경우: 값 자체를 키로 저장하므로 다른 값과 동일하게 처리한다.
- [ ] 모든 값이 서로 다른 경우: 끝까지 순회한 뒤 `False`를 반환한다.

**코드**

```python
class Solution:
    def containsDuplicate(self, nums: list[int]) -> bool:
        seen = {}
        for num in nums:
            if num in seen:      # 숫자가 이미 딕셔너리 키로 존재한다면 중복!
                return True
            seen[num] = True     # 숫자를 딕셔너리 키로 기록
            
        return False
```

**다시 볼 때의 트리거**
> 중복 여부만 필요하면 정렬보다 해시셋 또는 해시맵으로 본 값을 기록한다.

- **소요 시간 / 막힌 지점:** 해시맵에 이미 본 값을 기록하는 방식으로 해결했다.

## 4. Linked List Cycle

**[문제 링크](https://leetcode.com/problems/linked-list-cycle/)** · `Easy` · Python · `자력해결`

**입출력**
- 연결 리스트의 시작 노드 `head`가 주어진다. 리스트의 다음 노드가 이전에 방문한 노드를 가리킬 수 있다.
- 노드를 따라갔을 때 다시 방문한 노드가 있으면 `True`, `None`에 도달하면 `False`를 반환한다.

**접근**
1. 브루트포스: 각 노드에서 다음 노드로 이동하며 방문 여부를 기록한다.
2. 한계: 방문한 노드를 저장해야 하므로 노드 수에 비례하는 추가 공간이 필요하다.
3. 최종: 현재 노드를 `seen` 집합에 저장하고, 다음에 같은 노드를 다시 만나면 사이클로 판단한다.

**선택 근거**
노드의 값이 아니라 노드 객체 자체의 재방문을 확인해야 하므로, 방문한 노드 객체를 저장하는 집합을 사용한다.

**복잡도**
- 시간: `O(N)` — 사이클이 없으면 모든 노드를 한 번씩 방문한다.
- 공간: `O(N)` — 방문한 노드를 집합에 저장한다.

**엣지 케이스**
- [ ] `head`가 `None`인 경우: 반복문에 들어가지 않고 `False`를 반환한다.
- [ ] 노드가 하나이고 자기 자신을 가리키는 경우: 첫 방문 후 같은 노드를 다시 만나 `True`를 반환한다.
- [ ] 마지막 노드의 `next`가 `None`인 경우: 끝까지 방문한 뒤 `False`를 반환한다.

**코드**

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        seen = set()  # 방문한 노드를 저장할 집합
        current = head
        
        while current is not None:
            # 이미 방문한 노드라면 사이클 존재!
            if current in seen:
                return True
            
            seen.add(current)      # 현재 노드 기록
            current = current.next # 다음 노드로 이동
            
        return False  # 반복문이 끝났다 = None을 만났다 = 사이클 없음
```

**다시 볼 때의 트리거**
> 연결 리스트에서 같은 노드를 다시 방문하는지 확인하려면 노드 객체를 집합에 저장한다.

- **소요 시간 / 막힌 지점:** 방문한 노드를 값이 아니라 객체로 저장해야 한다는 점을 확인했다.

## 이번 주 패턴 정리

배열 문제에서는 해시맵으로 이전 값을 기억하거나, 현재까지의 최솟값·최댓값을 유지하면 전체를 한 번만 순회할 수 있다. 연결 리스트에서는 값이 같다는 사실보다 같은 노드 객체를 다시 방문했는지가 중요하므로 방문 집합을 사용한다.
