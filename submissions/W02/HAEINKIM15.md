## 1. Two Sum

**[문제 링크](https://leetcode.com/problems/two-sum/)** · `Easy` · Python · `해설봄`
<!-- 결과 태그: 자력해결 / 힌트봄 / 해설봄 — 솔직하게. 복습 리스트의 근거가 됩니다. -->

**입출력**
<!-- 입력 제약(길이·값 범위·중복·음수 여부)과 출력 형태. 1~2줄 -->
- 입력: 길이 2~10⁴의 정수 배열 `nums`와 정수 `target`이 주어지며, 음수와 중복 값 O
- 출력: 합이 `target`이 되는 서로 다른 두 원소의 인덱스를 반환한다. 정답은 정확히 하나 존재한다.


**접근**
<!-- 브루트포스 → 왜 부족한가 → 최종 아이디어 한 문장. 3줄 이내 -->
1. 브루트포스: target - 현재 값을 in으로 검색
2. 한계:in 이 O(n) 걸려서 전체 시간이 O(n²)이 걸림 
3. 최종:해시맵에 값: 인덱스를 저장하면서 필요한 값(target - num)이 이미 존재하는지 확인하여 한 번 돌면 끝.

**선택 근거**
<!-- 왜 이 자료구조/알고리즘인가. 1~2줄 -->
-정답으로 값이 아닌 인덱스를 반환해야 하므로 set 대신 값: 인덱스를 함께 저장할 수 있는 딕셔너리(해시맵)를 사용.O(1)걸림

**복잡도**
- 시간: `O(n)` — 배열 한 번돌아서 해시맵 조회함.
- 공간: `O(n)` — n개의 값을 해시맵에 저장함. 

**엣지 케이스** (최소 2개, 처리 방법까지)
- 같은 값 두 개가 정답인 경우 (nums = [3,3], target = 6) → 현재 값을 저장하기 전에 complement를 확인하므로 서로 다른 인덱스 [0,1]을 반환한다.
- 필요한 두 숫자가 배열의 앞뒤에 떨어져 있는 경우 (nums = [2,7,11,15], target = 17) → 이전에 확인한 값과 인덱스를 해시맵에 저장하므로 정상적으로 두 인덱스를 찾을 수 있다.

**코드**

```python
# LeetCode에서 Accepted 받은 코드를 그대로. 다듬지 않기.
class Solution(object):
    def twoSum(self, nums, target):
        seen = {}
        
        for index, num in enumerate(nums):
            complement = target - num

            if complement in seen:
               return [seen[complement],index]
            seen[num]=index
```

**다시 볼 때의 트리거**
> <!-- "두 달 뒤 이 문제를 만나면 무엇을 떠올려야 하는가" 한 문장 --> 두 수의 합이 target이 되는 인덱스 찾기 → target - 현재 값을 해시맵에서 찾고 값: 인덱스를 저장한다.

- **복습 필요:** 해시맵, `enumerate()`

## 2. Best Time to Buy and Sell Stock 

**[문제 링크](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)** · ` Easy` · Python · `힌트봄`

**입출력**
- 입력: 길이 1~10⁵의 정수 배열 `prices`가 주어지며, `prices[i]`는 i번째 날의 주식 가격이다.
- 출력: 한 번 사고 이후 한 번 팔아서 얻을 수 있는 최대 이익을 반환한다. 이익을 낼 수 없다면 0을 반환한다.


**접근**
1. 브루트포스:모든 매수일과 그 이후의 매도일 조합을 확인하여 최대 이익을 구한다.
2. 한계: O(n²)이 되어 입력 크기가 최대 10⁵일 때 비효율적
3. 최종: 최소 가격을 저장하고, 현재 가격과의 차이로 최대 이익을 갱신한다.

**선택 근거**
- 배열이 왼쪽에서부터 한 번 순회하니까 이전까지의 최저 가격만 저장하면 매수일이 매도일보다 앞서야한다는 조건을 만족한다. 

**복잡도**
- 시간: `O(n)` — prices를 한 번만 돈다.
- 공간: `O(1)` — 최소 가격과 최대 이익만 변수로 사용한다.

**엣지 케이스**
- [ 7,6,4,3,1 ] -> 이익을 낼 수 없으므로 0을 반환
- [5] -> 매도할 수 없으므로 0을 반환

**코드**

```python

 min_price = prices[0]
        max_profit = 0

        for i in prices:
            if i < min_price:
                min_price = i
            profit = i - min_price
            if profit > max_profit:
                max_profit = profit

        return max_profit

```

**다시 볼 때의 트리거**
> 배열 돌면서 지금까지의 최솟값과 현재 값의 차이를 계산한다.
