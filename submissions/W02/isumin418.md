## 1. Two Sum

**[문제 링크](https://leetcode.com/problems/two-sum/)** · `Easy` · Python · `힌트봄`
<!-- 결과 태그: 자력해결 / 힌트봄 / 해설봄 — 솔직하게. 복습 리스트의 근거가 됩니다. -->

**입출력**
-입력: 길이 2~10^4의 정수 배열 nums와 target이 주어짐. nums의값은 -10⁹~10⁹이고 음수와 중복 허용함.
-출력: 합이 target이 되는 서로 다른 두 원소의 인덱스를 배열 형태로 반환함. 정답은 정확히 하나 존재함. 

**접근**
<!-- 브루트포스 → 왜 부족한가 → 최종 아이디어 한 문장. 3줄 이내 -->
1. 브루트포스: 모든 두 원소의 조합을 확인하며 합이 target인지 검사함.
2. 한계: 두 원소의 모든 조합을 확인하면 시간복잡도가 O(n²)이 되어 비효율적임. 
3. 최종: 배열을 한 번 순회하면서 target - 현재값 이 이전에 등장했는지 해시맵에서 확인함. 

**선택 근거**
<!-- 왜 이 자료구조/알고리즘인가. 1~2줄 -->
- 해시맵은 특정 값의 존재 여부와 인덱스를 O(1)에 확인할 수 있어, 모든 조합을 비교하지 않고도 필요한 짝을 찾을 수 있음. 

**복잡도**
- 시간: `O(n)` — 배열을 한 번 순회하고, 각 해시맵의 조회와 삽입이 평균 O(1)
- 공간: `O(n)` — 최악의 경우 최대 n개의 값:인덱스 정보를 해시맵에 저장함. 

**엣지 케이스** (최소 2개, 처리 방법까지)
- [ ] 같은 값 두 개가 정답인 경우 (nums = [1,1], target = 2) - 현재 값을 해시맵에 저장하기 전에 필요한 값이 있는지 먼저 확인해 같은 원소를 중복 사용하는 것을 방지함. 
- [ ] 음수가 포함된 경우 - target-현재값을 그대로 계산하면 되므로 음수도 별도 처리 없이 해시맵 방식으로 해결 가능함. 

**코드**

```python
# LeetCode에서 Accepted 받은 코드를 그대로. 다듬지 않기.
```
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}

        for i, num in enumerate(nums):
            need = target - num

            if need in seen:
                return [seen[need], i]

            seen[num] = i

**다시 볼 때의 트리거**
> <!-- "두 달 뒤 이 문제를 만나면 무엇을 떠올려야 하는가" 한 문장 --> 두 수의 합이 target이 되는 문제라면 target-값을 계산하고, 이전 값을 확인할 때는 해시맵을 떠올리자.

## 2. Contains Duplicate

**[문제링크](https://leetcode.com/problems/contains-duplicate/)** · `easy` · python · `힌트봄`

**입출력**
-입력: 길이 1~10⁵의 정수 배열 nums가 주어지며 각 값의 범위는 -10⁹~10⁹임.
-출력: 같은 값이 두 번 이상 등장하면 true, 모든 값이 서로 다르면 false를 반환함. 

**접근**
1. 브루트포스: 모든 두 원소를 비교해 같은 값이 있는지 확인함.
2. 한계: 모든 원소 쌍을 비교하면 시간복잡도가 O(n²)이 되어 배열이 커질수록 비효율적임. 
3. 최종: 배열을 한 번 순회하며 본 값은 set에 저장하고 현재 값이 set에 있으면 중복으로 판단함. 

**선택 근거**
- set은 값의 존재 여부를 평균 O(1)에 확인할 수 있어 이전에 나온 값인지 빠르게 검사하는 데 적합함. 

**복잡도**
- 시간: `O(n)` — 배열을 한 번 순회하며 각 원소의 set 조회와 삽입을 평균 O(1)에 수행함.
- 공간: `O(n)` — 중복이 없을 경우 최대 n개의 값을 set에 저장함.

**엣지 케이스**
- [ ] 원소가 1개인 경우: 비교할 다른 값이 없으므로 중복이 없다고 판단해 false를 반환함. 
- [ ] 같은 값이 연속해서 등장하는 경우(nums = [1,1,2,3])-두 번째 1을 확인할 때 이미 set에 있으므로 즉시 true를 반환함.

**코드**

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        seen = set()

        for num in nums:
            if num in seen:
                return True
            seen.add(num)

        return False

```

**다시 볼 때의 트리거**
> 중복 여부만 빠르게 확인하면 되는 문제라면 set을 이용하자.
