## 2. 문제 제목

**[문제 링크](https://leetcode.com/problems/3sum/)** · `Medium` · Python · `해설 봄`

**입출력**
- 입력: 정수 배열 nums
- 출력: 합이 0이 되는 세 수의 유효한 조합 리스트 [nums[i], nums[j], nums[k]] (중복 조합 불가)

```

class Solution:

  def threeSum(self, nums: list[int]) -> list[list[int]]:
    res = []
    nums.sort()  # 1. 먼저 정렬하기

    for i in range(len(nums) - 2):
      # 2. 중복된 첫 번째 숫자는 건너뛰기 (중복 조합 방지)
      if i > 0 and nums[i] == nums[i - 1]:
        continue

      # 3. 투 포인터 설정 (남은 구간의 양 끝)
      left, right = i + 1, len(nums) - 1

      while left < right:
        total = nums[i] + nums[left] + nums[right]

        if total < 0:
          left += 1  # 합이 너무 작으면 왼쪽을 오른쪽으로 이동
        elif total > 0:
          right -= 1  # 합이 너무 크면 오른쪽을 왼쪽으로 이동
        else:
          # 정답을 찾았을 때
          res.append([nums[i], nums[left], nums[right]])

          # 4. 중복된 결과 방지를 위해 왼쪽/오른쪽 포인터의 중복 값들도 건너뛰기
          while left < right and nums[left] == nums[left + 1]:
            left += 1
          while left < right and nums[right] == nums[right - 1]:
            right -= 1

          # 다음 탐색을 위해 포인터 한 칸씩 안쪽으로 이동
          left += 1
          right -= 1

    return res
```
