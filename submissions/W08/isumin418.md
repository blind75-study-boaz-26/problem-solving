## 1. non-overlapping intervals (435)

**[문제 링크](https://leetcode.com/problems/non-overlapping-intervals/)** · `medium` · Python · `힌트봄`
<!-- 결과 태그: 자력해결 / 힌트봄 / 해설봄 — 솔직하게. 복습 리스트의 근거가 됩니다. -->

**입출력**
<!-- 입력 제약(길이·값 범위·중복·음수 여부)과 출력 형태. 1~2줄 -->
- 입력 : [시작 시간, 종료 시간] 형태의 구간 1개 이상 10⁵개 이하. 시간은 −50,000 이상 50,000 이하이고, 시작 시간은 종료 시간보다 작다. 음수 시간과 중복 구간도 가능
- 출력 : 남은 구간이 서로 겹치지 않도록 삭제해야 하는 최소 구간 수.

**접근**
<!-- 브루트포스 → 왜 부족한가 → 최종 아이디어 한 문장. 3줄 이내 -->
1. 브루트포스: 남길 구간의 모든 부분집합을 확인하고 겹치지 않는 구간을 최대 몇 개 남길 수 있는지 구한다. 
2. 한계: 구간이 n개면 부분집합이 2ⁿ개라 입력이 커지면 탐색하기 어렵다
3. 최종: 종료 시간순으로 정렬 -> 현재 구간의 시작 시간과 마지막으로 남긴 구간의 종료 시간을 비교 -> 현재 시간이 더 큰 경우: 남김 / 작은 경우 : 삭제 개수 + 1

**선택 근거**
<!-- 왜 이 자료구조/알고리즘인가. 1~2줄 -->
- 시작 시간이 빠른 구간부터 고르면 일찍 시작해 오래 이어지는 구간 하나가 여러 구간을 막을 수 있다. 반면 최적해의 첫 구간을 가장 일찍 끝나는 구간으로 바꿔도 뒤에 있던 구간을 모두 유지할 수 있으므로, 종료 시간 기준의 그리디를 선택했다
- 겹침 여부를 판단할때는 마지막으로 남긴 구간의 종료 시간만 필요하므로, 그 값을 변수 하나로 관리했다. 별도 리스트에 저장할 필요 없음

**복잡도**
- 시간: `O(nlogn)` — 구간을 종료 시간 오름차순으로 정렬하는 데 O(nlogn), 정렬한 구간을 한 번 순회하는 데 O(n)이 걸린다
- 공간: `O(n)` — python의 list.sort(key= ...)가 사용하는 보조 공간을 포함한 최악 기준이다. 

**엣지 케이스** (최소 2개, 처리 방법까지)
- [ ] 끝점만 닿는 경우 [[1,2], [2,3]] — 두 번째 구간의 시작 시간이 last_end와 같으므로 start >= last_end를 만족한다. 두 구간 모두 남기고 0을 반환한다.
- [ ] 같은 구간이 반복되는 경우 [[1,2], [1,2], [1,2]] — 첫 구간을 남긴 뒤 나머지는 모두 start < last_end이므로 각각 삭제하고 2를 반환한다.

**코드**

```python
# LeetCode에서 Accepted 받은 코드를 그대로. 다듬지 않기.
class Solution:
    def eraseOverlapIntervals(self, intervals: list[list[int]]) -> int:
        # 종료 시간이 빠른 구간부터 확인
        intervals.sort(key=lambda interval: interval[1])

        # 첫 구간을 남기고, 두 번째 구간부터 비교
        last_end = intervals[0][1]
        removed = 0

        for i in range(1, len(intervals)):
            start, end = intervals[i]

            if start >= last_end:
                last_end = end
            else:
                removed += 1
        return removed
        
```

**다시 볼 때의 트리거**
> 겹치는 구간을 최소한으로 지우려면, 가장 일찍 끝나는 구간부터 겹치지 않게 최대한 많이 남긴다.

## 2. word search (79)

**[문제 링크](https://leetcode.com/problems/word-search/)** · `medium` · python · `해설봄`

**입출력**
- 입력:  m × n 문자 격자 board와 문자열 word다. 1 ≤ m, n ≤ 6, 1 ≤ len(word) ≤ 15이며, 문자는 영문 대소문자로 이루어진다.
- 출력: 상하좌우로 이동하며 같은 칸을 한 경로에서 한 번만 사용해 word를 만들 수 있으면 True, 없으면 False를 반환한다.

**접근**
1. 브루트포스: 모든 칸에서 시작해 칸을 재사용하지 않는 len(word) 길이의 경로를 모두 만든 뒤, 경로의 문자열을 word와 비교한다.
2. 한계: 중간에 글자가 틀린 경로도 끝까지 만들기 때문에 불필요한 탐색이 많다. 
3. 최종: 첫 글자가 맞는 칸에서 DFS를 시작하고, 다음 글자와 맞지 않는 경로는 즉시 중단한다. 돌아올 때는 현재 칸의 방문 표시를 해제한다.

**선택 근거**
- 단어를 완성하는 경로 하나만 찾으면 되므로 DFS를 선택함. BFS는 같은 길이의 여러 후보 경로와 각 경로의 방문 정보를 큐에 보관해야 한다. DFS는 현재 경로의 방문 정보만 관리하면 된다. 
- 현재 경로에서 같은 칸을 다시 쓰는지 빠르게 확인하기 위해 좌표 포함 여부를 평균 O(1)에 검사할 수 있는 집합 visited를 사용한다. 

**복잡도**
- 시간: `O(m × n × 3^L)` — L은 단어의 길이다. 격자의 m × n개 칸이 시작점 후보이고, 첫 이동은 최대 4방향이다. 이후에는 직전에 칸으로 되돌아가는 방향이 즉시 제외되므로, 탐색이 이어지는 방향은 매 단계 최대 3개다.
- 공간: `O(L)` — 재귀 호출은 최대 L단계까지 쌓이고, visited에는 현재 경로에서 사용 중인 칸의 좌표만 저장한다.

**엣지 케이스**
- [ ] 단어가 한 글자인 경우 board = [["A"]], word = "A" — 시작 칸에서 첫 글자이자 마지막 글자를 맞췄으므로 바로 True를 반환한다.
- [ ] 같은 칸을 다시 밟아야 하는 경우 board = [["A", "B"]], word = "ABA" — A → B까지는 가능하지만 마지막 A는 이미 visited에 있으므로 다시 사용할 수 없다. 다른 경로도 없으므로 False를 반환한다.

**코드**

```python
class Solution:
    def exist(self, board: list[list[str]], word: str) -> bool:
        rows, cols = len(board), len(board[0])
        directions = [(-1,0),(1,0),(0,-1),(0,1)]
        visited = set()

        def dfs(r: int , c: int , i: int) -> bool:
            # 격자 밖이거나, 이미 사용한 칸이거나, 글자가 다르면 실패
            if not (0<=r<rows and 0<=c<cols):
                return False
            if (r,c) in visited or board[r][c] != word[i]:
                return False

            # 현재 칸에서 마지막 글자까지 맞췄으면 true
            if i == len(word) -1 :
                return True

            # 현재 칸을 경로에 넣고 이웃 칸에서 다음 글자를 찾음
            visited.add((r,c))

            for dr,dc in directions:
                if dfs( r + dr , c + dc , i + 1 ):
                    visited.remove((r,c))
                    return True
                
            # 모든 방향이 실패하면 현재 칸을 경로에서 빼고 돌아간다
            visited.remove((r,c))
            return False

        #격자를 한 칸씩 보면서 첫 글자가 맞는 칸에서만 dfs를 시작
        for r in range(rows):
            for c in range(cols):
                if board[r][c] == word[0] and dfs(r,c,0):
                    return True
            
        return False

```

**다시 볼 때의 트리거**
> 격자에서 같은 칸을 두 번 쓰지 않고 단어를 찾아야 하면, 다음 글자가 맞는 칸으로 DFS를 하고 돌아올 때 방문 표시를 푸는 백트래킹을 떠올린다.
