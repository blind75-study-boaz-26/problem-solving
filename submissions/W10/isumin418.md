## 1. Jump Game (55)

**[문제 링크](https://leetcode.com/problems/jump-game/)** · `Medium` · Python · `힌트봄`

**입출력**

- 입력은 길이 1~10,000의 정수 배열 `nums`다. 각 값은 0~100,000이고 중복이 가능하며, 해당 위치에서 앞으로 뛸 수 있는 최대 거리를 뜻한다.
- 인덱스 0에서 마지막 인덱스에 도달할 수 있으면 `True`, 아니면 `False`를 반환한다.

**접근**

1. 브루트포스는 현재 위치에서 가능한 점프 길이를 모두 시도한다.
2. 경로가 같은 위치에서 합쳐질 때 이후의 탐색을 반복하므로 입력이 크면 비효율적이다.
3. 왼쪽부터 한 번 순회하며 도달 가능한 인덱스에서만 `maxReach`를 갱신한다. 현재 인덱스가 범위를 벗어나면 실패하고, 범위가 마지막 칸까지 이르면 성공한다.

**선택 근거**

도달한 칸에서는 최대 거리 이내의 어느 칸으로든 뛸 수 있어, 도달 가능한 범위는 인덱스 0부터 연속이다. 따라서 경로를 저장하지 않고 오른쪽 끝만 추적하면 된다.

**복잡도**

- 시간 `O(n)` — 각 인덱스를 최대 한 번 확인한다.
- 공간 `O(1)` — 추가 배열이나 재귀 호출 없이 변수만 사용한다.

**엣지 케이스**

- `[0]` → `True`. 시작점이 마지막 칸이므로 첫 반복에서 성공한다.
- `[3,2,1,0,4]` → `False`. `maxReach`가 3에 머물러 인덱스 4에서 실패한다.
- `[2,0,0]` → `True`. 첫 점프로 가운데 0을 건너뛸 수 있다.

**코드**

```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        maxReach = 0
        for i in range(len(nums)):
            if i > maxReach:
                return False
            maxReach = max(maxReach, i + nums[i])
            if maxReach >= len(nums) - 1:
                return True
        return True
```

**다시 볼 때의 트리거**

> 각 칸에서 최대 거리 이내로 뛸 수 있다면, 도달 가능한 가장 먼 위치 하나만 추적한다.
