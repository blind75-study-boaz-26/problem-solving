## 1. Kth Smallest Element in a BST

**[문제 링크](https://leetcode.com/problems/kth-smallest-element-in-a-bst/)** · `Medium` · Python · `해설봄`

**입출력**
- 입력: 이진 탐색 트리의 루트 `root`와 정수 `k`. 노드 수는 1~10⁴개이며, `1 ≤ k ≤ 노드 수`이다. 노드 값은 중복되지 않는다.
- 출력: 트리에서 k번째로 작은 노드의 값 (정수).

**접근**
1. 브루트포스: 모든 노드의 값을 리스트에 저장하고 정렬한 후 `k-1`번째 값을 반환한다.
2. 한계: 정렬에 `O(n log n)` 시간이 필요하며 모든 노드 값을 저장해야 한다.
3. 최종: BST의 중위 순회(왼쪽 → 루트 → 오른쪽)를 스택으로 구현하고, 노드를 방문할 때마다 `k`를 감소시켜 `k == 0`이면 해당 값을 반환한다.

**선택 근거**
- BST는 왼쪽 서브트리의 값이 루트보다 작고 오른쪽 서브트리의 값이 크므로 중위 순회 시 오름차순으로 방문할 수 있다. 스택을 사용하면 재귀 없이 순회를 구현하고 k번째 노드에서 탐색을 종료할 수 있다.

**복잡도**
- 시간: `O(H + k)` — 가장 왼쪽 노드까지 내려가는 데 최대 H번, 이후 k번째 노드까지 방문한다. H는 트리의 높이이다.
- 공간: `O(H)` — 순회 과정에서 스택에 최대 H개의 노드가 저장된다.

**엣지 케이스**
- [x] `k = 1`: 가장 작은 값을 찾아야 하므로 가장 왼쪽 노드를 방문한 직후 반환한다.
- [x] `k = 노드 수`: 모든 노드를 중위 순회하여 마지막에 방문한 최댓값을 반환한다.
- [x] 노드가 하나뿐인 경우: 루트 노드를 스택에 넣었다가 꺼내고 `k == 0`이 되면 루트 값을 반환한다.

**코드**

```python
class Solution(object):
    def kthSmallest(self, root, k):
        stack = []
        current = root

        while current or stack:
            while current:
                stack.append(current)
                current = current.left

            current = stack.pop()
            k -= 1

            if k == 0:
                return current.val

            current = current.right
```

**다시 볼 때의 트리거**
> BST에서 k번째로 작은 값을 찾는다면 중위 순회를 떠올리고, 스택을 이용해 왼쪽 노드부터 방문하면서 k번째 노드에서 종료한다.

## 2. Construct Binary Tree from Preorder and Inorder Traversal

**[문제 링크](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)** · `Medium` · Python · `해설봄`

**입출력**
- 입력: 이진 트리의 전위 순회 결과 `preorder`와 중위 순회 결과 `inorder`. 두 배열의 길이는 같고 1~3000이며, 노드 값은 -3000~3000 범위의 중복 없는 정수이다.
- 출력: 두 순회 결과를 만족하도록 복원한 이진 트리의 루트 노드 `TreeNode`.

**접근**
1. 브루트포스: 전위 순회의 첫 번째 값을 루트로 선택하고, 중위 순회 배열에서 해당 값을 선형 탐색하여 왼쪽과 오른쪽 서브트리를 재귀적으로 구성한다.
2. 한계: 매 재귀 호출마다 중위 순회 배열에서 루트 위치를 탐색하면 최악의 경우 `O(n²)` 시간이 걸린다.
3. 최종: 중위 순회의 값과 인덱스를 해시맵에 저장하여 루트 위치를 `O(1)`에 찾고, 전위 순회 순서대로 노드를 생성하면서 재귀적으로 좌우 서브트리를 구성한다.

**선택 근거**
- 전위 순회는 `루트 → 왼쪽 → 오른쪽` 순서이므로 다음에 생성할 루트 노드를 알 수 있다. 중위 순회는 `왼쪽 → 루트 → 오른쪽` 순서이므로 루트 위치를 기준으로 서브트리의 범위를 나눌 수 있다.
- 해시맵을 사용하면 루트의 위치를 빠르게 찾을 수 있고, 재귀 함수를 이용하면 좌우 서브트리를 반복적으로 구성할 수 있다.

**복잡도**
- 시간: `O(n)` — 중위 순회 배열을 해시맵으로 만드는 데 O(n), 각 노드를 한 번씩 생성하는 데 O(n)이 필요하다.
- 공간: `O(n)` — 노드 위치를 저장하는 해시맵에 O(n), 재귀 호출 스택에 최악의 경우 O(n) 공간이 필요하다. 반환할 트리 자체의 공간은 제외한다.

**엣지 케이스**
- [x] 노드가 하나뿐인 경우: 해당 값을 루트 노드로 생성하고, 좌우 서브트리는 `None`을 반환한다.
- [x] 왼쪽 또는 오른쪽 자식이 없는 경우: 재귀 호출에서 `left > right`가 되면 `None`을 반환하여 빈 서브트리를 처리한다.
- [x] 한쪽으로 치우친 트리: 왼쪽 또는 오른쪽 서브트리만 연속으로 생성되더라도 재귀적으로 복원할 수 있다.

**코드**

```python
class Solution(object):
    def buildTree(self, preorder, inorder):
        index_map = {val: i for i, val in enumerate(inorder)}
        self.pre_idx = 0

        def build(left, right):
            if left > right:
                return None

            root_val = preorder[self.pre_idx]
            self.pre_idx += 1

            root = TreeNode(root_val)
            mid = index_map[root_val]

            root.left = build(left, mid - 1)
            root.right = build(mid + 1, right)

            return root

        return build(0, len(inorder) - 1)
```

**다시 볼 때의 트리거**
> 전위 순회에서는 루트를 찾고, 중위 순회에서는 루트를 기준으로 좌우 서브트리의 범위를 나눈 뒤 재귀적으로 트리를 구성한다.

## 이번 주 패턴 정리 (선택)

이진 트리의 순회 순서를 활용한다. 
KST smallest element는 **BST의 중위 순회**를 활용하여 노드를 오름차순으로 방문한다. 스택을 이용해 왼쪽 노드부터 탐색하고, k번째 노드를 방문하면 바로 값을 반환한다.

두 번째 문제는 **전위 순회와 중위 순회의 관계**를 활용하여 트리를 복원하는 문제. 전위 순회에서 루트를 선택하고, 중위 순회에서 해당 루트의 위치를 기준으로 좌우 서브트리를 구분한 뒤 재귀적으로 노드를 생성한다.

두 문제 모두 트리 순회의 특성을 이해하는 게 핵심이지만, 첫 번째는 기존 트리를 탐색하는 문제이고 두 번째는 순회 결과를 이용해 새로운 트리를 구성하는 문제라는 차이가 있다.
